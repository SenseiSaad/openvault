# IT Access Request Form

This built-in template is deployable with the backend (including Vercel). It is
used when the company has not uploaded its own IT access template.

## Template

```text
IT ACCESS REQUEST FORM - [Company]

1. REQUESTOR
* Full Name: [Full Name]
* Employee ID: [Employee ID]
* Department: [Department]
* Manager: [Manager's Name]

2. ACCESS REQUIRED
* System: [System Name]
* Role: [Access Role]
* Justification: [Business Justification]
* Start date: [Date]
* End date: [End Date]

3. APPROVALS
* Manager: [Manager's Name]
* Data owner: [Data Owner]
* Approved on: [Date]
```
